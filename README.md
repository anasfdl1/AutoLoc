# \# AutoLoc

# 

# \## Présentation du projet

# 

# AutoLoc est une plateforme de gestion de location de véhicules multi-agences.

# 

# L'objectif du projet est de permettre la gestion des véhicules, des locations, des clients et des différentes agences à travers une application centralisée.

# 

# \## Acteurs principaux

# 

# \### Client

# Le client peut consulter les véhicules disponibles et effectuer une demande de location.

# 

# \### Agent d'agence

# L'agent gère les opérations de location au niveau de son agence.

# 

# \### Responsable d'agence

# Le responsable supervise les activités de son agence et gère les ressources associées.

# 

# \### Administrateur

# L'administrateur assure la gestion globale de la plateforme et des utilisateurs.
